# PictureStore

**PictureStore** is a vibe coded image editor built with Python. The goal is to create a fun, accessible image-editing application with familiar tools for drawing, working with layers, adding text, and transforming images.

## ✨ Features

- 🖼️ **Layers** — Work with multiple layers in a single project.
- ✏️ **Drawing & Erasing** — Draw on your images and erase unwanted parts.
- 🔤 **Text Editing** — Add and edit text directly on the canvas.
- 🔄 **Transformations** — Move, resize, rotate, and transform layers.
- ↩️ **Undo & Redo** — Undo mistakes and redo changes.
- 📂 **Project Files** — Save and reopen your PictureStore projects.
- 🧲 **Magnetic Snapping** — Align layers with guides and snapping assistance.
